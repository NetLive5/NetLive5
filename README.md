Front-end разработчик
---------------------

Я веб-разработчик. Мой путь в IT начался с колледжа, где я познакомился с такими языками программирования, как C++, C#, Java, а также познакомился с основами веб-разработки (HTML, CSS, JavaScript). После окончания колледжа я поступил в университет на специальность "Информационные системы и технологии". Во время обучения я также попробовал свои силы в мобильной разработке с использованием React Native. С сентября 2023 года я начал обучение в Яндекс.Практикуме на направление Front-end разработчик, где продолжаю развиваться по сей день.
